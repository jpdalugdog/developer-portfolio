# John Paul — Developer Portfolio

Web Developer & BSIT Student portfolio. HTML5, CSS3, vanilla JavaScript only.

## Before deploying (all in `script.js` → `CONFIG`)
1. `email`, `github`, `facebook`, `linkedin`: add REAL links. Empty = hidden.
2. `repos` (quickbite, lunaCafe, elitecut, portfolio): add real GitHub repo URLs; "View Code" appears only when set.
3. CV (button stays hidden until ready): put your file at `assets/John-Paul-Dalugdog-CV.pdf`, then set `cvReady: true`.
4. Live Demo links are in `index.html` (`data-link`); update if the Vercel URLs change.

## Notes
- The contact form has no backend and sends nothing. With an email set, it opens a prepared mailto draft.
- Future form services: Formspree, Web3Forms, EmailJS (replace the submit handler).
